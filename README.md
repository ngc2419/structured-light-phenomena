# Structured Light Phenomena (SLP)

**An open empirical research programme exploring structured light as a coherent physical phenomenon with geometric, quantum, planetary, and consciousness-boundary dimensions.**

**Susan Delaney** · ORCID: [0009-0002-3854-1833](https://orcid.org/0009-0002-3854-1833) · License: [CC-BY-SA-4.0](LICENSE)

## Manuscript summary 

Structured Light Phenomena designates a class of reproducible, spatially coherent light behaviours that resist reduction to standard scattering or diffraction accounts. This repository archives the empirical record, formalisation efforts, sensor pipelines, and cross-domain extensions of the SLP research programme — including its intersection with Rotational Resonance Quantum Astronomy (RRQA).

The repository is a living document. Data, notebooks, and findings are versioned here; canonical releases are deposited to Zenodo and linked below.

**Status**: Active development — sensor pipeline and resonance agent in progress.
